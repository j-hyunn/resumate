> **방법과 한계**
> - 코드 정적 대조 + 기존 dev 서버 **:3000** curl(SSR). :3100은 뜨지 못해 쓰지 않았고, 서버를 시작·종료하지 않았다. 코드는 고치지 않았다.
> - **브라우저 클릭 흐름은 보지 않았다.** 동의 창 → 실행 이어짐, 카운트다운, 좁은 화면 배치, 클라이언트에서만 그려지는 문구는 코드 경로로만 확인했다.

> - HTTP 200은 존재 증거가 아니다. `notFound()`가 Suspense 안에 있어 없는 항목도 200으로 온다(예: 옛 저장소의 프로젝트 8). 그래서 문구 포함 여부로 판정했다.
