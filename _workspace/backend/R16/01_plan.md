## 변경

### A. `src/server/services/job-description/fetch.ts` — HTML → 마크다운 (api-engineer)
`htmlToText` 자리를 마크다운 변환으로 바꾼다. 세 경로를 모두 지난다(사람인·잡코리아 프레임, `JobPosting.description`, 일반 본문).

**새 의존성을 넣지 않는다.** 지금 코드처럼 정규식 기반으로 넓힌다. 기존 전처리(`stripDroppedElements`·`stripBoilerplateBlocks`·`decodeEntities`)는 그대로 쓴다.

| HTML | 마크다운 `[가정]` |
|------|------------------|
| `h1`~`h6` | `#`~`######` + 공백 (atx) |
| `ul > li` | `- ` |
| `ol > li` | `1. ` (번호 자동은 렌더러에 맡김) |
| `strong`·`b` | `**글자**` |
| `em`·`i` | `_글자_` — `*`를 쓰지 않는다(줄 첫머리에서 목록 기호와 헷갈림) |
| `br` | 줄바꿈 |
| `p`·`div` 등 블록 | **빈 줄로 구분**한다. 마크다운에서 줄바꿈 하나는 같은 문단 안의 줄바꿈으로 렌더되어 문단이 합쳐지기 때문이다 |
| `table` | **GFM 마크다운 표** `\| a \| b \|` + 머리 행 다음 구분 줄 `\| --- \|`. `<th>`가 없으면 첫 행을 머리 행으로 삼는다. 셀 안 `\|` → `\\|`, 셀 안 줄바꿈은 공백 하나로 접는다. colspan·행별 셀 수 차이는 빈 셀로 채운다. **(UI 확인 2026-11-12: 편집기 `DocTextarea`가 `TableKit`을 켜 두어 마크다운 표를 실제 표로 그린다 — 처음의 "셀은 탭"안 대체)** |
| `a` | **글자만 남긴다.** 공고 URL에는 추적 토큰이 붙는 경우가 있어 주소를 원문에 남기지 않는다(CF-A16과 같은 취지) `[가정]` |
| `img`·`script`·`style` | 지운다(지금과 같음) |

- 마크다운 문법 문자가 본문에 그대로 나오면(`*`·`_`·`#`·백틱) **지금은 이스케이프하지 않는다** `[가정]`. 공고 문장에 문법 문자가 우연히 섞여 렌더가 조금 달라지는 것이, 원문에 `\`가 섞이는 것보다 덜 해롭다고 본다.
- **`normalizeText`**: 줄 안 공백 접기, 빈 줄 3개 이상을 2개로 줄이기, 줄 앞뒤 trim은 유지한다. 중첩 목록 들여쓰기는 trim으로 평평해진다(허용).
- **`fetch_too_short`(200자)**: **문법 문자를 뺀 글자 수**로 판정한다. 기호 때문에 판정이 달라지지 않게 하기 위해서다.
- **50,000자 자르기**: 저장 상한이 마크다운 문자열 길이이므로 그대로 둔다. 다만 **줄 경계에서 자른다**(굵은 글씨 짝이 반쯤 잘리지 않게) `[가정]`.

### B. `src/server/ai/context-pack/jd.ts` `splitJdSentences` — 마크다운 가장자리 (ai-pipeline-engineer)
- 지금 `BULLET` 정규식은 목록 기호(`-`·`1.`·`>` 등)를 문장 앞에서 뗀다. 그런데 **제목 `#`은 떼지 않는다.** 또 `**`를 목록 기호 `*`로 오인해 `**주요 업무**` → `주요 업무**`처럼 반쪽만 뗀다.
- **문장 텍스트는 원문의 정확한 부분 문자열이어야 한다**(`start`/`end` 오프셋, 근거 검증 V-*). 그래서 **텍스트를 바꾸지 않고 `start`·`end`만 안쪽으로 옮긴다.**
  - 줄 첫머리 `#{1,6}` + 공백 → `start`를 뒤로 옮긴다.
  - **표 데이터 행**: 줄 첫머리 `|` + 공백, 끝의 공백 + `|`만 경계를 안쪽으로 옮긴다(안쪽 `|`는 그대로 둔다). 구분 줄 `| --- |`은 기호뿐인 세그먼트라 건너뛴다. 이스케이프된 `\|`는 셀 안 글자다.
  - 세그먼트 전체가 `**…**`(또는 `__…__`)로 감싸여 있으면 → 양 끝에서 2자씩 안쪽으로 옮긴다.
  - `BULLET`이 `**`를 목록 기호로 먹지 않게 한다(`*` 하나만 목록 기호로 본다).
- **기존 저장 데이터 영향 없음**: 저장된 공고는 문장 배열(`sentences` jsonb)을 저장해 두었으므로 다시 나누지 않는다. 미리 보기와 생성은 같은 배포의 같은 분할기를 쓴다. 분할 결과가 배포 사이에 바뀌면 문장 수 대조에서 `preview_mismatch`가 나와 안전하게 버려진다(CF-A17).
- **`prompt_version`은 올리지 않는다** `[가정]`. 프롬프트 문장은 그대로다. 마크다운 기호가 들어간 원문에서만 입력이 달라지며, 그 경우 `input_hash`는 자연히 달라진다.

## 확인 (테스트)
- 실제 사람인·잡코리아·`JobPosting` 픽스처(기존)에서 제목·목록·굵은 글씨가 마크다운으로 나온다. 문단이 빈 줄로 구분된다.
- **CF-A17**: `normalizeJdRawText`(가져온 문자열) → 해시·분할 → 생성 RPC 대조가 같은 문자열에서 일치한다.
- 분할: `## 자격 요건` → `자격 요건`, `- **필수**: Java` → 목록 기호만 떼고 원문 부분 문자열 유지, `**주요 업무**` → `주요 업무`. 모든 문장에서 `raw.slice(start,end) === text`가 성립한다.
- 기존 일반 텍스트 입력(마크다운 기호 없음)의 분할 결과가 **바뀌지 않는다**(회귀 단정).
- `fetch_too_short`: 문법 문자를 빼고 199자면 실패, 200자면 통과.
- 로그에 본문·URL 경로·쿼리가 없다(CF-A16, 기존 단정 유지).

- DB 변경이 없어 원격 마이그레이션은 없다. **코드 머지만 하면 된다.**
