- **C-6 진행 단계 값**: `prepare`(인사이트·면접 첫 단계), `synthesize_regen`(인사이트), `complete`(면접 두 작업)를 추가해야 한다.

  - 동기·스트리밍 경로의 재시도 대기: 동기(요건 추출)는 5초 이하만 요청 안에서 기다린다.

  - 스트리밍 서류(AI-03·AI-04)는 재생성하지 않고 `[수치 확인 필요]`로 바꾸고 플래그를 단다.

- **C-3 저장 키**: 결과 jsonb의 별칭 참조는 UUID 키로 바꿔 저장한다(`requirement_refs` → `requirement_ids`, `project_priorities[].ref` → `project_id`, `question_refs` → `question_ids` 등).
- **별칭 노출 금지**: 저장 문장의 별칭은 표시 이름으로 바꾼다. **AI-02 카드 예시 문장의 "PRJ-3"을 고쳐야 한다.**
- **AI-04 이벤트 순서**: `sources_selected → 블록 → (adjusting_length) → validated → done`. 카드는 `validated`가 `adjusting_length` 앞이다. 블록 id는 `validated`에서 확정되므로 화면은 그때 블록을 통째로 바꾼다.
- **AI-05 세트 구성 규칙**: 질문 단위 가능성 검사로 바꿨다(질문을 스트리밍으로 하나씩 저장하므로 세트 전체를 다시 만들 수 없음). 버린 만큼 1회 다시 만든다.
- **AI-06**
  - `consistency_notes` 원소는 `{text, answer_quotes, evidence}`다.
  - 답변 인용도 `interview_answer` 근거 행으로 남긴다.
  - 개선 답변 예시 재생성이 실패하면 첫 평가를 치환해서 저장한다.

  - 모델이 빠뜨린 요건은 `no_evidence`로 채운다.

- **근거 저장 직전 원본 삭제**: insert 트리거가 "원본 삭제됨"으로 저장한다.
