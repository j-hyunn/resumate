## MVP 한 문단 요약

경력직 이직자를 위한 대시보드형 웹 서비스다. 커리어·기업 JD·지원 현황은 AI 없이 동작하고, AI 기능은 사용자가 본인 API 키(OpenAI / Gemini / Claude 중 1개 활성)를 연결하면 열리는 선택 확장이다(BYOK). 운영자는 AI 비용을 부담하지 않는다. 왼쪽 메뉴는 **커리어 / 자기소개서 관리 / 모의 면접 / 지원 현황** 4개이고, 로그인하면 커리어 화면이 먼저 열린다.

- **커리어**: 왼쪽에 경력·교육·독립 프로젝트를 **시작 연도**별로 한 번씩 놓은 목록, 오른쪽에 고른 항목의 상세가 보이는 2단 화면이다. 시작은 "커리어 추가" 하나로 하고, 상세는 섹션마다 "수정"으로 고친다. 경력·교육 아래에는 프로젝트가 있고, 프로젝트마다 **STAR 1개**(상황 / 역할 / 행동 / 결과·성과 / 배운 점)를 쓴다. 프로젝트 카드(종류·이름·기간)를 누르면 프로젝트 상세 전체 페이지가 열리고, 오른쪽 **Resumate AI 패널**에서 대화로 STAR를 채운다(프로젝트마다 대화 기록 여러 개, AI는 사용자가 말한 내용만 정리하고 사용자가 확인해야 반영). 소속 없는 **독립 프로젝트**는 프로젝트 정보(기간·담당 업무·사용 기술·Link)·프로젝트 내용·산출물(제목 + 마크다운 본문, 여러 개)로 쓰고, 산출물도 AI 근거로 쓴다. 정량 성과는 따로 입력하지 않는다(결과/성과는 서술).
- **자기소개서 관리**: 지원 건마다 지원 프로젝트(화면 용어 **"자기소개서"**, 예: "{회사명 – 포지션명} 자기소개서")를 만들고 JD를 넣는다. 그 안에서 인사이트, 경력기술서, 자소서 문항 답변을 따로따로 만들 수 있고 서로 선후 관계가 없다. 커리어 데이터가 부족하면 그 자리에서 AI 대화로 채운 뒤 돌아온다. 자소서는 기본 3문항(지원 동기 / 직무 역량 / 입사 후 포부 및 성장 계획)으로 시작하고, AI가 문항별로 근거로 쓸 경력·프로젝트를 골라 보여 준다.
- **모의 면접**: 면접 유형(직무 / 컬처핏)을 먼저 고른다. 질문을 한 번에 만들고, 사용자가 답을 모두 입력해 한 번 제출하면 점수와 피드백이 나온다. 점수 산정 방식은 미정이다.
- **지원 현황**: 지원 프로젝트를 카드로 놓은 칸반 보드다. 인터뷰 전형 열로 옮기면 면접 준비로 바로 이동하는 팝업이 뜬다.

- **AI 연결(BYOK)**: 설정에서 공급자 키를 등록·검증·교체·삭제한다. Gemini 무료 키를 기본 추천하되, 무료 등급의 데이터 사용(Google 서비스 개선, 사람 검토 가능)은 따로 고지하고 동의를 받는다. 키는 외부 KMS 기반 봉투 암호화로 저장하고 서버에서만 쓴다.
- **사용량 미터**: 이번 달 Resumate에서 쓴 토큰과 예상 비용(가격표 기준 추정, 실제 청구액 아님)을 기능별·공급자별로 보여 준다.
- **한도 초과 안내**: 요청 한도, 일일 한도(Gemini 무료 초기화 시각은 KST로 표시), 결제 필요, 키 무효 등 7가지 원인별로 안내하고 공급자 대시보드로 연결한다.

모든 AI 출력은 사용자 데이터나 JD 안의 근거에 연결되고, 근거가 없는 내용은 지어내지 않고 자리 표시로 남긴다. 근거 검증은 공급자와 무관하게 서버에서 같은 규칙으로 한다.
