| 표 구분 줄 `| --- | :---: |` | 글자·숫자가 없어 기존 규칙대로 건너뜀(테스트 있음) |

## `[가정]`
1. **별표 하나 + 공백 없음(`*우대 경험`)도 목록 기호로 뗀다** — 지시는 "`*` 하나 + 뒤에 공백"이었지만, R16 전 분할기는 `*우대`의 `*`도 뗐다. "마크다운 없는 기존 입력의 분할이 바뀌지 않는다"를 우선해 공백 조건을 두지 않았다(`\*(?!\*)`). 마크다운 이탤릭 `*강조*`가 세그먼트 첫머리에 오면 앞 `*`만 떨어지는 경우가 생기지만 부분 문자열 규칙은 지켜지고, 가져오기 변환기가 이탤릭을 `*`로 내지 않으면 생기지 않는다.
2. **표 한 행 = 한 문장**: 셀로 쪼개지 않고, 셀 안의 `.`·`!`·`?`에서도 나누지 않는다(`| 업무 | API 설계. 운영 |` → `업무 | API 설계. 운영`). 셀 중간에서 끊으면 안쪽 `|`가 문장 가장자리에 남기 때문이다.
3. 이스케이프된 `\|`로 끝나는 줄은 **표 행이 아니다**(닫는 구분자가 없다) → 일반 텍스트로 그대로 둔다.
4. 일반 텍스트에서 바뀌는 드문 경우(회귀 표 밖): 줄이 `**`/`__`로 시작하거나 그 짝으로 통째로 감싸인 경우, `-*` 같은 섞인 기호 묶음, 줄이 `|`로 시작·끝나는 경우. 모두 마크다운 문법과 같은 모양이라 의도된 변화다.
