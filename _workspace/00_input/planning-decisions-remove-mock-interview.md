## 2. 문서별로 지워야 하는 것 (조사 결과)

### 2.1 PRD (01)
- "커리어 데이터 / JD 인사이트·서류 / AI 모의 면접 **3대 축**" → **2대 축**으로 고친다 (제목·개요·전략 서술 전부)
- 면접 기능군 요구사항(F-P3-* 계열: 면접 세션 시작, 질문 생성, 답변 작성, 채점, 종합 피드백, 면접 기록)
- MoSCoW 우선순위 표·MVP 범위 표의 면접 행
- 성공 지표의 면접 관련 지표
- 용어집의 면접 용어(모의 면접, 면접 유형, 루브릭, 앵커 등)
- 지원 단계 설명에서 면접 단계 2개 (RM-2)
- 설정 다이얼로그 AI 연결 안내 문구의 "모의 면접"(= 사용량 표 기능 행 `interview_questions`·`interview_evaluation`도 함께 사라진다)

### 2.2 유저 플로우·화면 명세 (02)
- 면접 화면: `S-20`(면접 질문 생성/준비), `S-22`(답변 작성), `S-33`/`S-37`/`S-39` 중 면접 기록·결과 화면 — 실제 번호는 문서에서 확인해 정확히 지운다
- 면접 플로우(FL-xx) 전체, 그리고 지원 프로젝트 상세·보드에서 면접으로 들어가는 진입점
- IA·사이트맵·화면 목록의 면접 항목, L-01 사이드바의 "면접 기록"
- 보드(칸반) 열에서 면접 단계 2개 (RM-2)
- 상태 목록(ST-xx) 중 면접 전용 상태, 공통 컴포넌트(C-xx) 중 면접 전용 컴포넌트(점수 표시 등)
- 복귀 대상(`job_interview`) · 데이터 충분성 게이트의 면접 분기
- 사용량 표 기능 행 2개

### 2.3 AI 기능 명세 (03)
- `AI-05` 면접 질문 일괄 생성, `AI-06` 답변별 평가, `AI-07` 세션 종합 피드백 — 명세 전체
- 4.1절 면접 유형별 질문 구성 규칙, 4.2절 참고 평가 기준(루브릭)
- `AI-10` 꼬리 질문(`[보류]`) — 면접 후속이므로 함께 지운다
- C-14 출력 길이·개수 상한 표의 AI-05~AI-07 행
- C-13 사용량 미터 기록의 면접 feature 2개
- 근거 규칙·V-x 검증 중 면접 전용 항목(`interview_question`·`interview_answer` 근거 출처, 앵커·데이터 충분성 등급)
- 공통 절(C-x)에 섞인 면접 예시·언급

### 2.4 데이터 모델 (04)
- A.12~A.13 면접 엔티티: `interview_sessions`, `interview_questions`, `interview_answers`, 답변 평가·세션 피드백 저장 구조

- 커리어·계정 삭제 영향(삭제 파급)에서 면접 분기, 보존·퍼지 정책의 면접 테이블
