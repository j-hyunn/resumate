## MVP 한 문단 요약

경력직 이직자를 위한 대시보드형 웹 서비스다. 커리어·기업 JD·지원 현황은 AI 없이 동작하고, AI 기능은 사용자가 본인 API 키(OpenAI / Gemini / Claude 중 1개 활성)를 연결하면 열리는 선택 확장이다(BYOK). 운영자는 AI 비용을 부담하지 않는다. 왼쪽 메뉴는 **커리어 / 기업 JD 관리 / 모의 면접 / 지원 현황** 4개이고, 로그인하면 커리어 화면이 먼저 열린다.

- **커리어**: 연도 > 경력·교육 > 프로젝트 > 상세 내용 계층으로 정리한다. 상세 내용은 STAR(상황 / 과제 / 행동 / 결과)와 회고 및 배운 점으로 쓴다. 폼으로 직접 쓰거나 AI와 채팅하며 쓸 수 있고, AI는 사용자가 말한 내용만 정리하며 저장은 사용자가 확인한 뒤에 한다.
- **기업 JD 관리**: 지원 건마다 지원 프로젝트를 만들고 JD를 넣는다. 그 안에서 인사이트, 경력기술서, 자기소개서를 따로따로 만들 수 있고 서로 선후 관계가 없다. 커리어 데이터가 부족하면 그 자리에서 AI 대화로 채운 뒤 돌아온다. 자소서는 기본 3문항(지원 동기 / 직무 역량 / 입사 후 포부 및 성장 계획)으로 시작하고, AI가 문항별로 근거로 쓸 경력·프로젝트를 골라 보여 준다.
- **모의 면접**: 면접 유형(직무 / 컬처핏)을 먼저 고른다. 질문을 한 번에 만들고, 사용자가 답을 모두 입력해 한 번 제출하면 점수와 피드백이 나온다. 점수 산정 방식은 미정이다.
- **지원 현황**: 지원 프로젝트를 카드로 놓은 칸반 보드다. 인터뷰 전형 열로 옮기면 면접 준비로 바로 이동하는 팝업이 뜬다.

- **AI 연결(BYOK)**: 설정에서 공급자 키를 등록·검증·교체·삭제한다. Gemini 무료 키를 기본 추천하되, 무료 등급의 데이터 사용(Google 서비스 개선, 사람 검토 가능)은 따로 고지하고 동의를 받는다. 키는 외부 KMS 기반 봉투 암호화로 저장하고 서버에서만 쓴다.
- **사용량 미터**: 이번 달 Resumate에서 쓴 토큰과 예상 비용(가격표 기준 추정, 실제 청구액 아님)을 기능별·공급자별로 보여 준다.
- **한도 초과 안내**: 요청 한도, 일일 한도(Gemini 무료 초기화 시각은 KST로 표시), 결제 필요, 키 무효 등 7가지 원인별로 안내하고 공급자 대시보드로 연결한다.

모든 AI 출력은 사용자 데이터나 JD 안의 근거에 연결되고, 근거가 없는 내용은 지어내지 않고 자리 표시로 남긴다. 근거 검증은 공급자와 무관하게 서버에서 같은 규칙으로 한다.
