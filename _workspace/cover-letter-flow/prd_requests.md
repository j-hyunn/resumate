## ux-planner (UX v5.19)

1. **폐기**(CF-1·CF-7, 기존 취소선 방식): S-45 경력기술서 작성, S-31 지원 프로젝트 허브, S-17 서류 목록, S-14 전체 페이지 생성 화면. S-15 JD·요건과 S-16 인사이트는 독립 화면이 아니라 **작성 화면 탭 "채용 공고"·"인사이트"**(CF-A12 `[가정]` — Q53-2 원문 수정 포함, 탭 이동이 저장 안 한 본문을 잃지 않음). 본문 탭 이름 "자소서"(CF-A13).
2. **흐름**(CF-7·CF-8): S-13 목록 → 추가 2단계 모달 → 문항 설정 → 작성. 문항 설정과 작성은 **같은 주소의 두 상태**(CF-A11 `[가정]`). FL-03·FL-10·FL-11을 다시 그려 주세요. PRD F-AP-01·02·03, F-DOC-02 (1).
3. **목록 행**(CF-9·CF-A8·CF-A9·CF-A14): "{기업 명} 자기소개서" / 포지션 / 만든 날 + D-day(마감일 있을 때만), "최근 작성 순" 하나, 행 메뉴 = 삭제(단계 이동 없음), 서류 수·전형 단계·진행 표시 없음.
4. **모달 2단계 채움 우선순위 — 확인 요청**: PRD는 "키가 있으면 AI 추출값, 키가 없으면 URL 가져오기의 `JobPosting` 값, 둘 다 없으면 빈 칸"으로 적었습니다(CF-A6 + CF-A15를 합친 읽기 `[가정]`). **키가 있고 `JobPosting` 값도 있을 때 어느 쪽이 이기는지, 추출이 도는 동안 2단계가 어떤 상태로 보이는지**(로딩 / 빈 칸 먼저 열고 나중에 채움)는 입력 문서가 정하지 않았습니다 — UX·AI가 정해 회신해 주세요. PRD는 회신대로 F-AP-01 (2)를 고칩니다.
5. **URL 가져오기 실패 문구**(CF-10): "이 공고는 가져오지 못했어요. 내용을 직접 붙여넣어 주세요"를 2단계 공고 내용 칸 자리에. 실패 판정은 10초·2MB·리다이렉트 3회·200자 미만(CF-A15 `[가정]`). 성공해도 2단계에서 고칠 수 있음.
6. **이관 손실 안내 자리**(F-DOC-04 (4)): 안내가 있던 서류 목록(S-17)이 폐기됐습니다. 자기소개서 목록(S-13)과 작성 화면 중 어디에 둘지 정해 주세요. 그리고 **경력기술서 초안은 전부 "옮기지 못한 초안"**(CF-A1)인데 경력기술서를 열 화면이 없어 관찰 기간 동안 **어디서 읽고 복사하는지**가 비어 있습니다 — PRD는 `[결정 필요]` CLA-Q3에 묶었습니다. 두 안(관찰 기간 동안만 읽기 전용 보기 / 화면 없이 운영자 덤프 요청 경로만)을 비교해 회신해 주시면 리더가 사용자에게 올립니다.
7. **답변 제목**(CF-6·CF-A4 `[가정]`): 문항마다 "문항 이름 · 제목 · 내용". 제목은 글자 수에 세지 않고, 제안 [반영]은 제목·본문을 함께 채웁니다.
8. **마감일 입력**(CF-4): 일 단위 날짜 선택(시안의 연·월 선택은 자리표시자), 비울 수 있음. 문항 설정·작성 화면 머리에서 고침.
9. **문항 상한 "문항 추가 n/5"**(CF-5), 문항 메모는 문항 설정에서 접고 작성 화면 문항 옆에서 연다(CF-A10 `[가정]`).
10. **보드 카드**(F-ST-01): D-day는 값이 있을 때만, 진행 표시는 "자소서 작성 중 / 작성됨"만(CF-A14 `[가정]`), 카드 → 작성 화면.
11. **요건 추출 다시 실행 자리**: 추출이 모달 [다음] 뒤로 옮겨졌습니다(CF-A6). 그때 실패했거나 키 없이 만든 자기소개서에서 추출이 도는 자리("작성 시작" / 대화를 열 때 / 채용 공고 탭의 "요건 정리하기")를 S-18·S-46·채용 공고 탭에 맞춰 정리해 주세요.

## ai-feature-designer (AI 명세 v4.14)

1. **AI-03 폐기**(CF-1), AI-04만 남김. 공통 규칙(AI-12·AI-13 공유)은 그대로. F-DOC-11은 지원 프로젝트당 대화 1종.
2. **AI-01 출력에 `deadline`**(`YYYY-MM-DD` 또는 null, CF-A5 `[가정]`) — 연도 없는 날짜·"상시 채용"은 null, 저장은 마감일이 비어 있을 때만. 추출 자리가 모달 [다음] 뒤로 옮겨짐(CF-A6) — C-6 순서와 6.4 "JD 요건 추출 15초" 목표를 그 자리에 맞춰 주세요.
3. **AI-04 출력에 문항별 `answer_title` 제안**(CF-6·CF-A4 `[가정]`, ≤ 100자). 글자 수 규칙(90~110%)은 본문에만, 제목은 세지 않음. 제한 값은 사용자가 문항 설정에서 넣은 값(CF-5).
4. **CL-Q1 비용 재계산**(PRD 6.5·9.0): 예시 월 비용 (a)·(b) 수치가 경력기술서 대화를 포함합니다. **PRD는 새 숫자를 쓰지 않았고** "CF-1로 경력기술서 대화가 빠져 재계산 필요 — AI 명세 v4.14 7장"으로만 표시했습니다. 7장에서 다시 계산해 주시면 PRD가 그 값을 옮깁니다. 자소서 3문항 $0.37 행은 유지로 읽었습니다 — 바뀌면 알려 주세요.
5. **사용량 `feature`**(CF-A3 `[가정]`): `career_description`은 과거 행 보존용, 새 기록 없음. **이번 달에 남은 과거 `career_description` 기록을 "자기소개서 작성 AI 채팅" 행에 합쳐 보일지**는 입력 문서가 정하지 않았습니다(PRD F-AI-07 (2)에 "AI·DM이 정한다"로 적음) — 데이터 모델과 함께 정해 회신해 주세요.
6. **URL 가져오기는 AI 기능이 아닙니다**(CF-A15·CF-A16 `[가정]`): 모델 매핑·사용량·`ai_jobs` 대상이 아니고, 다만 가져온 텍스트가 AI-01 입력이 됩니다. 사람인·잡코리아 등 사이트별 본문 추출 결과가 AI-01 입력 품질(주변 글 섞임)에 주는 영향을 평가 세트에 넣을지 판단해 주세요(NFR-AI-04).
7. **NFR-AI-04 평가 세트**에서 경력기술서 세트를 빼 주세요(CF-1).
