## 시안에서 읽은 것 — 화면별

### S-14 추가 모달 (`add-application-dialog.tsx`)
- 넓은 모달(시안 약 830px), **두 단계 모두 같은 크기**. 머리: 제목 **"자기소개서 추가"** + 닫기(X). 단계 표시(StepIndicator)·부제("공고 URL 또는 …")는 **시안에 없다**.
- ① 섹션 제목 **"JD 입력"** · 라벨 **"포지션 공고"** + 입력(자리 표시 `https://www.jd.com`) · 라벨 **"직접 입력"** + 큰 텍스트 영역(자리 표시 **"포지션 공고 내용을 입력해주세요."**) · 바닥 오른쪽 **[다음]**.
- ② 섹션 제목 **"지원 기업 / 포지션"** · 라벨 **"지원 기업"**(자리 표시 "기업 명") · **"지원 포지션"**("포지션 명") · 섹션 제목 **"공고 내용"** · 라벨 **"직접 입력"** + 큰 텍스트 영역 · 바닥 오른쪽 **[자기소개서 작성]**.
- 상시 보이는 보조 문구("URL과 직접 입력은 하나만…", "AI를 연결하면…")는 시안에 없다 → **상황이 생겼을 때만**(충돌·오류·Q53-1 게이트) 보인다. 진행 중 표시는 버튼 안 글자/스피너로.

### S-13 목록 머리 (`applications/page.tsx`, `application-list.tsx`)
- 위 바: 사이드바 토글 + "자기소개서 관리"(L-01 공통 머리 그대로).
- 본문 위 줄: 왼쪽 **정렬 표기 "최근 작성 순"**(시안은 칩 모양 + ⌄) — 확정상 선택지가 없으므로 **같은 칩 모양의 고정 표기**로(⌄는 빼거나 비활성 — `[UI-가정]`으로 기록), 오른쪽 주 버튼 **"⊕ 자기소개서 작성"**(`CirclePlus` 아이콘). 별도 큰 페이지 제목은 시안에 없다.
- 행 목록은 시안에 없으므로 지금 구성(이름·포지션·만든 날·D-day)을 디자인 시스템 표 모양 그대로 둔다.

### S-46 공통 머리 (L-02, `cover-letter-screen.tsx`)
- L-02 셸 그대로(로고 · [저장하기] · 계정). 카드 안 맨 위: **뒤로 버튼(둥근 사각) + 이동 줄**("자기소개서 관리 › {기업 명} 자기소개서" — 문항 설정 상태는 시안에 "› 자기소개서 상세"가 하나 더 있다: **S-10·S-44의 이동 줄 규칙**을 따르고 다르면 `[UI-가정]`).
- 큰 제목 **"{이름}"**(굵게) → 아래 **라벨/값 줄**: 왼쪽 회색 라벨 열(시안 "마감일", 약 140px) + 오른쪽 컨트롤. 줄: **마감일**(일 단위, 시안 셀렉트와 같은 높이·테두리 모양) · **지원 직무** · **JD 상세**(확정 항목). → 그 아래 **전폭 구분선**.
- **S-10·S-44의 머리(`DocHead`류)가 이미 이 모양이면 그것을 쓴다** — 새로 만들지 마라.

### S-46 문항 설정 상태 (`question-setup.tsx`, `question-fields.tsx`)
- 가운데 좁은 열(시안 약 830px), 위아래 여백 넉넉히. 제목 **"자기소개서 문항 추가"** + 회색 부제 **"작성하고자 하는 자기소개서 문항을 입력해주세요"**.
- 문항 한 줄 = **[문항 입력(넓게)] [글자 수 숫자 입력 + "자" 접미사(약 140px)]** — 라벨 없음, 자리 표시는 기본 문항 문구(K-28).
- 마지막 줄: 왼쪽 **"+ 문항 추가 n/5"**(고스트), 오른쪽 주 버튼 **[자기소개서 작성 시작]**.
- 시안에 **기준(공백 포함/제외)·메모·행별 라벨이 보이지 않는다** → 확정 항목이라 없애지는 말고 **기본 화면에서 숨겨** 시안 모양을 맞춘다(예: 행 끝 작은 ⋯ 메뉴나 행에 포커스했을 때만 — 방법은 `[UI-가정]`으로 기록). 문항 삭제도 같은 자리.

### S-46 작성 상태 (`answer-tab.tsx`, `cover-letter-panel.tsx`)
- 구분선 아래 **3단**: 왼쪽 **세로 탭**(약 190px, 선택 탭은 회색 바탕 알약 — "자소서" · "채용 공고" · "인사이트") · 가운데 본문 · 오른쪽 **Resumate AI 패널**, 본문과 패널 사이 **크기 조절 손잡이**(시안 x≈1355의 세로 막대). **S-10·S-44와 같은 3단 배치·손잡이**를 쓴다.
- 본문: 머리 **"자기소개서"**(굵게) + 오른쪽 ⋯. 문항마다: **문항 문장(작은 회색)** → **제목**(굵게, 자리 표시 "제목") → **내용**(자리 표시 "내용"). **테두리 있는 입력 상자가 아니라 문서형 입력**이다 → **L-02의 `DocTitleInput`·`DocTextarea`**(S-10·S-44가 쓰는 것)를 쓴다. 글자 수 표시·AI 제안 표식·문항 ⋯는 시안에 크게 드러나지 않으니 **작게, 필요할 때만**.
- **AI 패널은 공통 `AiPanel`(`src/components/career/ai-panel/`)을 써야 한다** — 지금 `cover-letter-panel.tsx`는 공통 `AiPanel`·`Message`·`Bubble`·`MessageScroller`·`PanelInput`을 하나도 쓰지 않고 생 `Textarea`로 따로 그렸다(사용자가 지적한 "공통 컴포넌트 미사용"의 핵심). 시안 패널: 머리 "Resumate AI" + ☰(기록) · +(새 대화) · ⋯ · ×, 아래 빠른 칩 줄, 입력창 "Resumate AI에게 물어보세요" + 보내기 — **공통 패널 그대로**.
  - 방법: 서류 대화 컨트롤러(`use-cover-letter-panel.ts`)가 `AiPanel`이 읽는 `AiPanelController` 모양을 채우는 **어댑터**를 두고 `<AiPanel panel={…} renderProposal={…QuestionProposalCard…} />`로 그린다. `useAiPanel`(S-10·S-44, 889줄)은 **고치지 않는 것을 우선**한다 — 고쳐야 하면 S-10·S-44 동작이 바뀌지 않게 기본값을 지금 동작으로.
  - 서류 대화만의 것(초안 턴 6회 칩, 문항 번호, CF-S8 자동 저장 `beforeTurn`, 다시 연 대화 근거 라벨)은 지금 동작 그대로 유지.
