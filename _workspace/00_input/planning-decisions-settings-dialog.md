# 결정 입력 — 새 설정 다이얼로그 (사이클 slug: `settings-dialog`)

- 작성일: 2026-11-05
- 출처: 사용자가 올린 새 설정 다이얼로그 화면 3장(계정 / AI 연결 / 약관). "개선 요청" 탭은 화면 없음
- 기준 문서 버전: PRD v4.13, UX v5.16, AI v4.11, DM v4.11
- 사용자 확정: `AskUserQuestion` 2라운드(2026-11-05) — SD-1 ~ SD-6
- 적용 범위: **설정 다이얼로그(S-24·S-40·S-42·S-25 진입·S-30 진입)와 그로 인해 바뀌는 프로필·동의·사용량 명세**. 자기소개서 작성의 채팅형 전환은 **이 사이클 밖**(SD-4)

## 1. 화면에서 읽은 것 (현행 기획 대비)

### 1.1 다이얼로그 구조
현행 S-24 섹션 7개(계정 · AI 연결 · AI 사용량 · 동의 관리 · AI 데이터 처리 · 처리방침·약관 · 회원 탈퇴)
→ 새 화면 **왼쪽 탭 4개: 계정 · AI 연결 · 약관 · 개선 요청**

### 1.2 계정 탭
- "계정" — 이메일 한 줄(읽기 전용)
- "내 정보" — 이름 / 구직 상태 / 관심 기업군 · 관심 산업 / 관심 직군 · 관심 직무(+ 셀렉트 한 칸 더) / 최종 학력(학교 명 · 학위 · 졸업 상태 · 기간 · 전공 · 학점)
- "위험 구역" — [로그아웃] [회원 탈퇴]
- 피그마 자리표시자: 이름 입력의 placeholder "직책 입력", 모든 셀렉트의 placeholder "고용 형태 선택" — 실제 문구가 아니다

### 1.3 AI 연결 탭
- "모델 공급자 설정" + 안내 "본인 AI 키를 연결하면 연결한 모델의 한도 내에서 인사이트·서류 초안·모의 면접·AI 작성 대화를 쓸 수 있어요"
- 공급자 카드 3개 → **한 줄짜리 라디오 행 3개**: Gemini "무료/유료 가능"(선택됨, ⋯ 메뉴) / GPT "GPT Pro 플랜 이상만 가능" [연결] / Claude "Claude MAX 플랜 이상만 가능" [연결]
- "모델 공급자 별 사용량 확인"(= S-42가 같은 탭 안으로) + 상시 고지 + **공급자 탭(Gemini·GPT·Claude)** + "{공급자} 대시보드 ↗"
- 표: 기능 | 입력 비용 | 호출 수 | 출력비용, 기능 행 **7개**(프로젝트/산출물 작성 AI 채팅 · 요건 추출 · 인사이트 · 자기소개서 작성 AI 채팅 · 면접 질문 · 면접 채점 · 연결 확인)
- 하단 안내 2줄(포함 범위 / 1분 반영)은 현행 그대로

### 1.4 약관 탭
- "Resumate 약관" — 개인정보 처리방침 · 이용 약관 · 국외 이전 약관 · **AI 데이터 처리** 각 [전문 확인]
- "선택 동의" — 이용 패턴 기록 활용(토글) / 기능 업데이트, 소식 받기(토글)
