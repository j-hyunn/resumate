## 1. 개요

### 1.1 한 줄 정의
경력직 이직자가 **커리어** 메뉴에 경력·교육·프로젝트를 STAR 구조로 정리하고, 지원하는 회사마다 **지원 프로젝트**(화면: 기업 JD)를 만들어 JD를 모으고, **지원 현황** 보드에서 전형 단계를 관리하는 커리어 관리 서비스. **본인 AI 키를 연결하면** 같은 데이터를 근거로 인사이트, 경력기술서·자기소개서 초안, 모의 면접, AI 작성 대화를 쓸 수 있다.

### 1.2 해결하려는 문제
| # | 문제 | 설명 | 해결 수단 |
|---|------|------|-----------|
| PB-1 | 경력이 정리되어 있지 않다 | 경력이 여러 회사·프로젝트에 흩어져 있고, 성과 수치는 기억에 의존한다 | 커리어(키 불필요) + AI 작성 대화(키 필요) |
| PB-2 | JD마다 어필 포인트를 찾기 어렵다 | 같은 경력이라도 JD에 따라 강조할 부분이 다르다 | 인사이트(키 필요) |
| PB-3 | 서류 작성 반복 비용이 크다 | 지원처마다 다시 쓴다. 범용 AI는 없는 경험을 섞는다 | 서류 초안(키 필요) |
| PB-4 | 경력직 면접 준비 수단이 부족하다 | "그 프로젝트에서 본인이 뭘 했나"를 깊게 묻는다 | 모의 면접(키 필요) |
| PB-5 | 지원 건별 준비물과 진행 상황이 흩어진다 | JD, 자소서, 면접 준비, 전형 단계가 뒤섞인다 | 기업 JD 관리 + 지원 현황 보드(키 불필요) |

### 1.3 왜 이 구조인가 (v4)
- **AI는 선택 확장**이다(사용자 확정). 커리어 정리와 지원 관리만으로도 노션·엑셀보다 나은 구조를 준다. AI가 없을 때도 쓸 이유가 있어야 키를 연결할 동기도 생긴다.
- **BYOK**: 사용자가 본인 키로 토큰 비용을 직접 낸다. 운영자는 AI 비용을 부담하지 않으므로 서비스 쪽 무료 한도·비용 상한이 필요 없다. 대신 사용자가 자기 비용을 이해할 수 있게 **사용량 미터**와 **한도·오류 안내**를 준다.
- **Gemini 무료 키**를 기본 추천 경로로 둔다(확정 2026-10-28 (사용자), UB-4): 결제 등록 없이 발급되어 진입 장벽이 가장 낮다. 대신 무료 등급은 입력이 공급자 서비스 개선에 쓰이고 사람이 검토할 수 있다는 정책이 있는 것으로 파악되어, 연결할 때 반드시 고지하고 **별도로 동의**를 받는다(F-AI-04, 확정 2026-10-28 (사용자)). 정책 문구 자체는 구현 전 최신 약관으로 확인한다 `[가정]`.
- 어떤 공급자를 쓰든 **근거 기반 원칙**은 같다: AI는 사용자가 쓰지 않은 사실을 만들지 않고, 모든 출력은 커리어 데이터·JD로 추적된다.

## 3. 제품 구조와 핵심 작업

### 3.1 내비게이션 (대시보드형 왼쪽 메뉴)

```
왼쪽 메뉴 (모든 화면 공통, 4개 고정 — 확정 2026-10-24 (사용자), U-4)
├── 커리어  ← 로그인 후 기본 첫 화면                      [키 불필요]
│     연도 > 경력 / 교육 > 프로젝트 > 상세 내용 (STAR + 회고 및 배운 점)
│     작성: 폼 직접 입력 [키 불필요] / AI와 대화하며 작성 [키 필요]
│
├── 기업 JD 관리  ← 지원 프로젝트 목록·생성·상세          [키 불필요]
│     지원 프로젝트 1개 = JD 1개 (확정 2026-10-24 (사용자), U-6)
│       ├── JD (공고 원문 [키 불필요] + 추출된 요건 [키 필요])
│       ├── 인사이트                                      [키 필요]
│       ├── 서류: 경력기술서 / 자기소개서 초안              [키 필요]
│       └── 모의 면접 세션                                 [키 필요, 지난 세션 열람은 불필요]
│
├── 모의 면접  ← 모든 지원 프로젝트의 면접 세션 모아보기 + 새 면접 시작 [새 면접은 키 필요]
│
└── 지원 현황  ← 지원 프로젝트 카드 칸반 보드 (전형 단계 6열) [키 불필요]

계정 영역 (메뉴 하단 또는 프로필 메뉴, 메뉴 4개와 별도) [가정]
└── 설정 > AI 연결  ← 공급자 키 등록·활성 공급자·사용량 미터·데이터 사용 고지 (F-AI)
```

- **데이터 소속**: 모든 데이터는 커리어(사용자 1명당 1개) 또는 지원 프로젝트(여러 개)에 속한다. "모의 면접"·"지원 현황" 메뉴는 지원 프로젝트 데이터의 보기이자 진입점이다. AI 연결 정보(키, 활성 공급자, 동의, 사용량)는 사용자 계정에 속한다.
- **순서 없음**: 어느 메뉴도 다른 메뉴의 완료를 요구하지 않는다. AI 기능은 커리어 데이터를 읽기 전용으로 쓴다.
- **첫 화면**: 로그인 후 항상 커리어 [가정]. 커리어가 비어 있으면 "직접 입력"을 기본 시작점으로, "AI와 대화하며 정리하기"는 키 연결 여부에 따라 바로 시작 또는 잠금 상태(F-AI-06)로 보인다.
